# Lab Summary

I chose **Path 2**, refactoring the provided Meal Planner starter notebook. I separated API invocation, JSON parsing, Pydantic validation, response formatting, email construction and SMTP delivery into focused functions; added explicit API, JSON, schema and configuration error handling; removed embedded email credentials in favor of environment variables; and changed the email action to use the plan currently displayed rather than generating another one. The main challenge was keeping the original seven-recipe/five-ingredient behavior while making error paths testable without paid API calls. I learned that a successful AI demo is not enough: clear failure boundaries, consistent outputs, local tests and correct UI state are necessary for dependable integration.
